Video and URL launcher with North Pennines National Landscape colour scheme.

Usage:
Place videos in "Movies/Kiosk Videos/" with the file name that you want to appear in the app.

Place a file named "Kiosk URLs.txt" containing the titles separated with a pipe ( | ) into "Documents/Kiosk URLs/"
e.g. Explore North Pennines | https://explore.northpennines.org.uk/

1 URL per line is required and all folder names are case sensitive.

"Documents" and "Movies" are preexisting directories, but "Kiosk Videos" and "Kiosk URLs" must be manually created.
