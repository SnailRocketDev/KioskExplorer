Kiosk Launcher with North Pennines National Landscape colour scheme.

Usage:\n
Place videos in "Movies/Kiosk Videos/"\n

Place a .txt file containing the titles separated with a pipe ( | ) into "Documents/Kiosk URLs/"\n
  e.g. Explore North Pennines | https://explore.northpennines.org.uk/\n

1 URL per line\n

"Documents" and "Movies" are preexisting directories, but "Kiosk Videos" and "Kiosk URLs" must be manually created.
