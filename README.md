Kiosk Launcher with North Pennines National Landscape colour scheme.

Usage:
Place videos in "Movies/Kiosk Videos/"

Place a .txt file containing the titles separated with a pipe ( | ) into "Documents/Kiosk URLs/"
  e.g. Explore North Pennines | https://explore.northpennines.org.uk/

1 URL per line

"Documents" and "Movies" are preexisting directories, but "Kiosk Videos" and "Kiosk URLs" must be manually created.
